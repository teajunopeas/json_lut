# Checklist - Antes de proponer un cambio

Usa esta lista antes de sugerir una nueva equivalencia, un ajuste de créditos o una sustitución.

## 1. Entender el problema

- [ ] ¿Hay un problema real y no solo una intuición?
- [ ] ¿Sé qué asignatura o conjunto de asignaturas está afectado?
- [ ] ¿La necesidad viene de contenido, resultados, créditos o restricción académica?

## 2. Revisar el estado actual

- [ ] ¿He leído el RAM actual o el caso afectado?
- [ ] ¿La equivalencia actual ya es aceptable?
- [ ] ¿Hay observaciones previas que deban conservarse?

## 3. Comparar alternativas

- [ ] ¿He comparado al menos una alternativa razonable?
- [ ] ¿La comparación se apoya en contenidos, resultados o ambos?
- [ ] ¿He descartado opciones solo parecidas pero académicamente débiles?

## 4. Comprobar restricciones

- [ ] ¿El semestre es compatible?
- [ ] ¿Los créditos encajan sin sobreasignar destino?
- [ ] ¿La solución respeta la movilidad y el equilibrio global del RAM?

## 5. Decidir

- [ ] ¿La propuesta mejora el conjunto?
- [ ] ¿No rompe una parte ya consolidada?
- [ ] ¿Puedo justificarla en pocas frases técnicas?
- [ ] ¿Puedo explicar qué riesgo queda abierto?

## Salida

- Proponer.
- Proponer con reserva.
- No proponer todavía.
