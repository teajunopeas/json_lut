# Checklist — Antes de modificar una equivalencia o el reparto de créditos

Usa esta lista antes de escribir en el JSON, cambiar una tabla o guardar una nueva versión del RAM.

## 1. Estado y motivo

- [ ] ¿Estoy trabajando sobre la última versión identificada del RAM?
- [ ] ¿He guardado o puedo recuperar la versión anterior?
- [ ] ¿Sé qué problema concreto intento resolver?
- [ ] ¿El problema está documentado por una regla, una guía o una observación del coordinador?
- [ ] ¿He convertido la observación en un criterio verificable?

## 2. Protección de lo ya válido

- [ ] ¿La equivalencia afectada está marcada `OK` o validada?
- [ ] Si lo está, ¿existe una razón imprescindible para tocarla?
- [ ] ¿He comprobado antes opciones menos invasivas?
- [ ] ¿El cambio mejora realmente el RAM global y no solo una fila aislada?

## 3. Evidencia académica

- [ ] ¿He revisado contenidos, resultados o ambos según la estrategia más adecuada?
- [ ] ¿Los elementos esenciales de origen siguen cubiertos después del cambio?
- [ ] ¿La evidencia procede de documentación real y no solo de título o embeddings?
- [ ] ¿He identificado y anotado cualquier hueco que permanezca?

## 4. Créditos y restricciones

- [ ] ¿He consultado la capacidad actual con las herramientas del proyecto?
- [ ] ¿Los ECTS asignados no superan los ECTS disponibles en destino?
- [ ] ¿El reparto parcial de créditos está permitido y es trazable?
- [ ] ¿El cambio reduce o al menos no empeora el número de déficits?
- [ ] ¿Respeta semestre, periodo de movilidad, nivel, acceso y prerrequisitos?

## 5. Impacto y trazabilidad

- [ ] ¿He comparado al menos una alternativa razonable?
- [ ] ¿Sé qué otras equivalencias se verán afectadas?
- [ ] ¿La modificación tiene una justificación breve y verificable?
- [ ] ¿He registrado el cambio, el motivo y la fuente?
- [ ] ¿El cambio se aplicará a una nueva versión de trabajo, no destruyendo la última validada?

## Decisión

- [ ] Aplicar cambio.
- [ ] Proponer para revisión, sin aplicar todavía.
- [ ] No modificar: falta evidencia o el impacto global no compensa.
