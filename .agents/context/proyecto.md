# Contexto del proyecto

## Propósito

Este repositorio reúne herramientas y memoria de trabajo para construir y refinar un RAM de movilidad entre la ULPGC y LUT University.

El objetivo no es decidir por similitud superficial, sino mantener un RAM defendible, coherente y estable en conjunto.

## Qué hace el sistema

- conserva catálogos estructurados de ULPGC y LUT;
- permite buscar candidatos por texto y semántica;
- ayuda a repartir ECTS y comprobar capacidad;
- conserva el estado de trabajo del RAM;
- exporta borradores legibles para revisión humana.

## Archivos clave

- `context/indice.md`: orden de lectura según la tarea.
- `context/normas_ram.md`: reglas operativas del RAM.
- `context/ram_actual.md`: estado de trabajo del RAM vigente.
- `context/ulpgc.md`: contexto del origen ULPGC.
- `context/lut.md`: contexto del destino LUT.
- `context/subdirector.md`: criterios operativos ya consolidados.
- `casos/`: expedientes concretos y restricciones especiales.
- `decisions/`: decisiones trazables ya tomadas.
- `scripts/README.md`: apoyo técnico para los scripts del proyecto.

## Principios de uso

- Usa los scripts para obtener datos; interpreta tú la decisión.
- No sustituyas una equivalencia válida sin una mejora global clara.
- Si una propuesta afecta al conjunto, analiza el conjunto.
- Si falta evidencia, marca el punto como abierto en vez de inventarlo.
- Conserva trazabilidad: problema, alternativas, decisión y riesgo.
