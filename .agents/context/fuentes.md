# Fiabilidad de la evidencia

## Convención de etiquetas

- `[CONFIRMADO]`: el agente puede tratarlo como hecho operativo en este proyecto.
- `[REVISAR]`: no debe cerrarse sin comprobación explícita.
- `[INFERENCIA]`: conclusión prudente a partir de varias observaciones.
- `[PENDIENTE]`: todavía no sirve como criterio de decisión.

## Regla práctica

- Priorizar siempre la documentación primaria y el estado actual del RAM.
- No convertir una conversación, un borrador o una coincidencia de nombres en norma.
- Cuando un dato sea útil pero no esté del todo cerrado, conservarlo como `[REVISAR]`.
- Cuando el dato ya esté validado dentro del flujo de trabajo, escribir el hecho sin añadir procedencia innecesaria.
