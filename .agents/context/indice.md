# Índice de contexto y decisiones

Lee solo lo necesario; no cargues la base de conocimiento completa por defecto.

## Si la tarea es entender el proyecto o el flujo

1. `AGENTS.md`
2. `prompts/PROMPT_MAESTRO_RAM.md`
3. `context/proyecto.md`
4. `context/herramientas.md`
5. `context/fuentes.md`

## Si la tarea es buscar candidatos LUT

1. `skills/buscar-candidatos/SKILL.md`
2. `context/lut.md`
3. `context/ulpgc.md`
4. `casos/descartadas.md`
5. el caso específico, si existe

## Si la tarea es evaluar una equivalencia

1. `skills/evaluar-equivalencia/SKILL.md`
2. `context/ulpgc.md`
3. `context/lut.md`
4. `context/normas_ram.md`
5. `context/subdirector.md`
6. `context/ram_actual.md` si ya existe un RAM base
7. el caso específico y decisiones relacionadas

## Si la tarea es ajustar créditos

1. `skills/ajustar-creditos/SKILL.md`
2. `context/normas_ram.md`
3. `casos/creditos.md`
4. `checklists/antes_de_modificar.md`
5. decisiones relacionadas

## Si la tarea es refinar un RAM ya revisado

1. `skills/refinar-ram-existente/SKILL.md`
2. `context/subdirector.md`
3. `context/normas_ram.md`
4. `context/ram_actual.md`
5. `casos/` afectados
6. `decisions/` relacionadas
7. la última tabla, JSON o Markdown del RAM

## Si la tarea es justificar o exportar

- Justificar: `skills/generar-justificacion/SKILL.md`, `plantillas/justificacion.md` y la evidencia académica concreta.
- Exportar: `skills/exportar-y-verificar/SKILL.md`, `checklists/antes_de_exportar.md` y `plantillas/informe.md` cuando haya resumen de revisión.

## Prioridad de fuentes

1. fuente oficial o correo original verificable;
2. `context/normas_ram.md` y reglas confirmadas;
3. `context/subdirector.md` con la observación ya consolidada;
4. decisiones confirmadas;
5. casos específicos;
6. scripts y datos locales;
7. plantillas.

Las etiquetas `[REVISAR]`, `[INFERENCIA]` y `[PENDIENTE]` nunca deben tratarse como norma definitiva.
