# Registro de decisiones

Esta carpeta conserva decisiones relevantes para el RAM y evita repetir análisis ya cerrados.

## Qué registrar

- equivalencias mantenidas de forma deliberada;
- sustituciones aprobadas;
- créditos ajustados;
- alternativas relevantes descartadas;
- observaciones del coordinador;
- problemas que siguen abiertos y no deben forzarse.

## Qué no registrar

- resultados brutos del matcher;
- candidatos sin revisar;
- ideas iniciales sin validar;
- búsquedas repetitivas;
- material que ya esté explicado por completo en una guía docente.

## Estados permitidos

- `propuesta`;
- `pendiente_de_confirmacion`;
- `confirmada`;
- `descartada`.
